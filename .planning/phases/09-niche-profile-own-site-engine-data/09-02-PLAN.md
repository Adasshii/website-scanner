<objective>
Build the installers niche profile: one typed module tree that holds every parameter the engine
reads, so changing country, locale, trade, competitor radius or copy is a change to the profile and
nothing else.

Purpose: NIC-04 is an architectural claim, and this plan is where it becomes provable. The profile
type is what makes NIC-02's citation requirement a compile error instead of a review miss, and what
makes D-9-21's separation of "has a value" from "shows a money line" impossible to get wrong by
accident.

Output: `lib/niche-profile/` (types, index, and the four `installers/` modules),
`types/niche-scan-slice.ts` (the slice the scanner receives), and two test files, one for the
profile's own contents and one for the NIC-03 / NIC-04 isolation assertions.
</objective>
