| Boundary | Description |

| browser (admin UI) → shortlist/release routes | Admin-authenticated requests; the release request spends scan budget |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-auth-ui | Elevation of Privilege | shortlist GET route | high | mitigate | Copies the exact `x-admin-secret` gate from app/api/admin/stats (V4); no new unauthenticated admin surface — the UI reuses the existing sessionStorage secret; acceptance grep verifies the gate |
| T-03-budget-ui | Denial of Service / budget | ReleaseButton | high | mitigate | The button never sends a ceiling; the route hard-codes `RELEASE_CEILING` (Plan 03). Mandatory `window.confirm` shows the exact count + ceiling before any request; disabled at zero eligibility |
| T-03-xss | Information Disclosure | ShortlistTable rendering | low | accept | Domain/score values are rendered as React text nodes (auto-escaped) and links use `https://{domain}` with a normalised registrable domain; no `dangerouslySetInnerHTML`. Rationale: React default escaping covers this at single-tenant scale |
| T-03-SC | Tampering | npm installs | high | mitigate | No installs; no shadcn/icon library — hand-rolled components reusing existing Tailwind classes (03-UI-SPEC) |
