## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| triage script → arbitrary prospect websites | Server-side fetch of untrusted third-party URLs and their redirect chains |
| redirect Location → next fetch | Each hop's target is attacker-controllable and may point at internal/metadata IPs |
| target response body → local process | Untrusted, unbounded-size body streamed onto Joshua's machine (D-10 runs locally) |
