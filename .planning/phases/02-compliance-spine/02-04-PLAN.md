## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| email recipient (untrusted) → GET/POST /api/unsubscribe/[token] | Public, unauthenticated endpoint; the only trust is a valid HMAC token. |
| resolved email → suppressions write | The route resolves the address server-side from the token's prospect_id; the address never appears in the request. |
