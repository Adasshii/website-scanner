## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| audit reader → lia_versions | A past send's LIA-version reference must always point at the exact assessment that applied; the row must be tamper-proof. |
| config change → legal_regimes | Adding a country is a data change (INSERT), never a code change; app code must read this table, not branch on country. |
