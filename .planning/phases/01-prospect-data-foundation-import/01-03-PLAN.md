<objective>
Build the identity/dedupe heart of the phase: `normalizeDomain()` (public-suffix-aware,
via tldts) and `upsertOverturePlace()` (the GERS-first-then-domain branching that makes
re-import idempotent, collapses same-domain records, and freezes Joshua's work by
omission). Prove it with a unit suite and a DB-backed integration suite covering every
IMP-03/04/05 and D-05/D-13/D-14 behavior.

Purpose: This is the durable-list-survives-re-import guarantee. Postgres cannot express
dual-identity dedupe in one upsert (two arbiter indexes on two tables), so the branching
lives in application code, each branch a single-table write.
Output: lib/domain-normalize.ts, lib/prospect-upsert.ts, and their test suites, green.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted Overture row → upsert → DB | Overture-sourced fields (names, addresses, URLs, category) are third-party input written into the DB |
| re-import → Joshua's committed work | A re-run must not silently overwrite triage/lifecycle/approval/contact state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Tampering | malformed/typed-wrong Overture fields reaching upsert | medium | mitigate | Writes go through the Supabase client (parameterized — no string-built SQL, no injection surface); OverturePlaceRow typing + normalizeDomain returning null on garbage; per-row failures surface to the caller for log-and-skip (plan 01-04). |
| T-01-05 | Tampering (Integrity) | re-import overwriting triage_score / lifecycle_state / contact_email / country | high | mitigate | Freeze-by-omission: work columns and country never appear in an UPDATE payload; website_url/country changes recorded as *_pending, never applied. Integration suite asserts each freeze truth. |
| T-01-06b | Spoofing | GERS-ID churn producing a duplicate prospect | low | accept | Domain-collapse branch (IMP-04) is the safety net; a reassigned GERS ID still collapses via domain. Documented in RESEARCH Pitfall 4; no extra control warranted at 10–50/week. |
