# Quick Task 260806-p6f: Category autocomplete on the import form

## Why

260806-ntm shipped the Import form with a free-text Category field, and flagged at the
time that a wrong value returns zero rows with no error. Joshua hit it immediately: he
typed `tandarts` three times and got nothing each time. Overture's categories are
English slugs, so the Dutch word could never match. The correct value was `dentist`,
947 places in Noord-Holland with 848 of them carrying a website.

The zero-row panel worked exactly as designed. It reported the truth. It just had no
way to say what to type instead, and there was no way to discover a valid value from
inside the tool.

## What changed

A category vocabulary is generated by `npm run overture-categories` into
`data/overture-categories.json`, keyed by the same `<ISO2>:<region-slug>` format as
`REGION_BBOXES`. A dev-only GET route reads it from disk and the Import form fetches
one region's list whenever country or region changes, filtering as you type.

Each suggestion shows the with-a-website count, not just the raw place count, because
that is the number that decides whether a category is worth importing. Some categories
look large and are mostly dead ends: `bridge` has 662 places and 125 websites.
